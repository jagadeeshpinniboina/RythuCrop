About RythuCrop

An intelligent agriculture prediction platform.

🌾

RythuCrop is a machine learning based agriculture application that uses agricultural and environmental parameters to estimate crop yield.

The system accepts information such as crop, crop year, season, state, cultivated area, production, rainfall, fertilizer and pesticide usage.

The submitted information is processed by a trained machine learning model and the system provides a predicted crop yield.
